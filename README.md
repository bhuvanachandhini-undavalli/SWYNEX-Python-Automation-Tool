# Python Student Report Automation

## Description

This project is a simple Python automation tool that generates student reports automatically.

The program calculates:
- Total marks
- Average marks
- Pass or Fail result

## How It Works

The program takes student names and marks as input data, calculates the total and average, and automatically generates a formatted report.

## Technologies Used

- Python

## How to Run

1. Open `student_report_automation.py`
2. Run the program using a Python compiler.
3. The student reports will be generated automatically.

## Output

The program displays each student's name, total marks, average marks, and result.
